# Research Workspace (ResearchQuoter) sürümleri

Bu depo yalnızca Research Workspace masaüstü programının kurulum dosyalarını barındırır; kaynak kod burada değildir.

- İlk kurulum için [son sürümün](../../releases/latest) sayfasından `Research-Workspace-Setup-<sürüm>.exe` dosyasını indirip çalıştırın.
- Kurulumdan sonra program yeni sürümleri kendisi indirir ve yeniden başlatmanızı önerir; tekrar kurulum dosyası indirmeniz gerekmez.
- Projeleriniz ve PDF'leriniz bilgisayarınızda kalır, güncellemeler onlara dokunmaz.
